# Orbit fitting for 433 Eros from real telescope observations

AIT 203 Optimization, course project (Milestones 2 & 3)
Kushman Goyal (BC2025051) · Siddharth Arya (BC2025092) · Manvik Kumar Gupta (BC2025059)

We recover the orbit of the near-Earth asteroid 433 Eros from **real astrometric
observations** (telescope measurements of its direction on the sky) published by the
Minor Planet Center. We solve the problem twice:

* **easy**: a convex, unconstrained linear least-squares problem (truncated f–g series,
  "how far does the orbit pass beside each line of sight", measured in au);
* **hard**: the real, non-convex problem (exact Kepler motion, light-travel time,
  telescope positions on the rotating Earth, misses measured as angles, bounds on the
  elements), solved with a trust-region least-squares method started from the easy answer.

JPL's published orbit is used **only at the end**, as an independent answer key. JPL's
current solution for Eros (orbit #659) was computed in 2021 from observations up to
May 2021; the observations we fit are from Oct–Dec 2025, so JPL never saw them.

## Running it

```bash
pip install -r requirements.txt
python3 fetch_data.py            # once; downloads into data/raw/ (needs internet)
python3 run_all.py               # whole pipeline, ~1-3 minutes
python3 run_all.py --quick       # skip the multi-start / landscape experiments
python3 -m tests.test_recovery   # code check: solvers recover a known orbit from perfect data
```

## What's where

| file | what it does |
|---|---|
| `fetch_data.py` | downloads MPC observations + observatory codes, and JPL tables used for checking |
| `run_all.py` | the full pipeline; writes `results/` and `figures/` |
| `src/constants.py` | GM of the Sun, speed of light, obliquity, unit conversions |
| `src/geometry.py` | time scales, Earth's position, telescope positions, RA/Dec ↔ vectors, light time |
| `src/kepler.py` | Kepler's equation, elements ↔ state vector, two-body propagation |
| `src/data.py` | parsers for MPC (80-column + ADES) and Horizons files, cleaning |
| `src/easy.py` | the convex problem: builds `A`, `b`, solves, scans r̄, optimality certificate |
| `src/hard.py` | the non-convex problem: residuals, bounded least squares, outlier rejection, covariance |
| `src/analysis.py` | JPL comparison, predictions, multi-start, slices, ablation, arc-length study |
| `src/plots.py` | every figure (two colour themes: `slide` and `paper`) |
| `tests/test_recovery.py` | noise-free self-test of both solvers (a code check, not an experiment) |
| `deck/make_backgrounds.py` | draws the slide backgrounds (noise + lines, no photos) |

## Where every figure comes from

All figures are produced by `run_all.py` from the downloaded data; nothing is drawn by hand
or generated by an image model. `*_slide.png` and `*_paper.png` are the same plot in two themes.

| figure | function in `src/plots.py` | data behind it |
|---|---|---|
| `sky_track` | `sky_track()` | MPC observations + hard-fit prediction |
| `obs_per_night` | `obs_per_night()` | MPC observations in the fit window |
| `stations` | `station_bars()` | MPC observations, observatory names from ObsCodes |
| `geometry_view` | `geometry_view()` | hard-fit orbit + Earth positions (ERFA) |
| `rbar_scan` | `rbar_scan()` | easy problem solved over a grid of r̄ |
| `residuals_time`, `residual_hist` | `residuals_vs_time()`, `residual_histogram()` | hard-fit residuals |
| `easy_vs_hard_misses` | `easy_vs_hard_misses()` | both solutions scored with the angular objective |
| `prediction_error` | `prediction_curves()` | our orbits vs JPL Horizons, and vs later MPC observations |
| `multistart`, `landscape`, `slice_M0` | `multistart_plot()`, `landscape()`, `slice_plot()` | hard objective explored around/away from the optimum |
| `ablation` | `ablation_bars()` | hard fit with one piece of physics removed at a time |
| `arc_length` | `arc_length_plot()` | fits to the first 3…61 days of data |

## Data sources

* Minor Planet Center (IAU), observations of (433) Eros via the `get-obs` API,
  https://data.minorplanetcenter.net/api/get-obs ; observatory codes,
  https://www.minorplanetcenter.net/iau/lists/ObsCodes.html
* JPL Horizons system, https://ssd.jpl.nasa.gov/horizons/ (validation only)
* JPL Small-Body Database, https://ssd-api.jpl.nasa.gov/sbdb.api (validation only)
* IAU SOFA / ERFA via astropy (Earth ephemeris, Earth rotation, precession–nutation)
